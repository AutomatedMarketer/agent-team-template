# inbox

Everything your agents produce lands here, one dated folder per day:

    inbox/2026-08-18/monday-brief.md
    inbox/2026-08-18/research-0914.md

## Why it is shaped this way

Every filename carries the agent and the moment it ran, so **no two writers can ever touch the
same file**. Your laptop, your travel machine and a cloud run can all write at once and there
is nothing to merge.

That is not a tidiness rule. It is the reason syncing across machines does not produce git
conflicts you would have to resolve by hand - and you should never have to resolve one.

Finished, curated work moves out of here. `inbox/` is where things arrive, not where they live.
