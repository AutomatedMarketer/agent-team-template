# Collecting the raw material

Content that sounds like the owner starts from things the owner actually said. This step
gathers those things; it writes nothing for publication.

## 1. Where to look

- `agents/content/notes/` — the drop folder. Voice-note transcripts, pasted thoughts,
  links, screenshots-turned-text. Anything the owner threw in since the last run.
- `inbox/` — recent dated folders, for anything another agent produced that reads like a
  content idea (a research finding, a customer question that keeps recurring).
- `agents/content/output/` — the last few drafts, so you know what was already written
  and do not pitch the same idea twice.

## 2. What to extract

For each usable piece of raw material, capture:

- **The idea, in the owner's own words** — quote the note, do not paraphrase it away.
  The phrasing in a voice note is the voice; it is the most valuable thing in the file.
- **Where it came from** — file path, so the drafting step can read the full note.
- **What it could become** — post, caption, short script, newsletter section. One guess,
  not a menu.

## 3. Rank, honestly

Order the list by how alive the idea is: specific beats general, a story beats an
opinion, something the owner said twice beats something they said once.

If the drop folder is empty and nothing in `inbox/` qualifies, the correct output is a
short note saying exactly that. Do not pad the list with ideas the owner did not have —
a generic idea in this list becomes a generic post in their feed.

## 4. Hand off

Leave the ranked list — idea, source path, suggested form — for the drafting step. It
reads the original notes through your paths, so a wrong path is a lost idea.
